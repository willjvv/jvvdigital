# JVV Digital Website

A modern, high-performance website for JVV Digital, built with Astro and deployed on GitHub Pages.

## Features

- **Blazing Fast**: Built with Astro for optimal performance
- **SEO Optimized**: Structured for both Google and AI answer engines
- **Mobile First**: Fully responsive design
- **Modern Tech Stack**: Astro + Tailwind CSS
- **GitHub Pages**: Easy deployment

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
3. Run the development server:
   ```bash
   npm run dev
4. Open http://localhost:4321
